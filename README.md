# Google vs Facebook Marketing Campaign Results

## 📊 Excel Data Analytics Dashboard

A Data Analyst project focused on analyzing and comparing marketing campaign performance across Google and Facebook using Microsoft Excel.

The project transforms advertising campaign data into summary tables, analysis, and an Excel dashboard to understand campaign performance and key marketing metrics.

## 🎯 Project Objective

The objective of this project is to analyze marketing campaign data and understand:

- Campaign performance
- Marketing channels
- Customer demographics
- Device usage
- Age distribution
- Sub-channel performance
- Key advertising metrics
- Differences between Google and Facebook campaigns
